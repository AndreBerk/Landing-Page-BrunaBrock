# Landing-Page-BrunaBrock
Landing Page focada em conversão e catálogo digital para boutique de locação de trajes de festa.

Projeto front-end desenvolvido para a boutique física Bruna Brock Trajes para Festa, focada no nicho de noivas e madrinhas. O objetivo da página é apresentar o alto padrão da loja, expor o catálogo de forma elegante e direcionar o cliente para o agendamento no WhatsApp.

### Foco do Projeto
*   **UX/UI Design Elegante:** Interface sofisticada focada no público feminino de alto padrão.
*   **Mobile First:** 100% otimizado para celulares, de onde vêm 90% dos acessos do Instagram da loja.
*   **Conversão Direta:** Botões de CTA (Call to Action) estratégicos integrados diretamente ao WhatsApp da equipe de vendas.
*   **Performance:** Carregamento rápido de imagens de alta resolução (vestidos) sem perda de qualidade.

### Tecnologias Utilizadas
*   HTML5, CSS3, JavaScript
*   Otimização de Imagens e SEO Local (Cuiabá-MT)
*   Hospedagem e configuração de domínio
